# Границы первой версии и дальнейшая разработка

Реализованный продукт — первая нативная играбельная версия TECH EMPIRE, а не вся долгосрочная концепция.

| Этап исходного задания | Состояние |
|---|---|
| Аудит | Найден и сохранён существующий репозиторий, создана ветка `feat/playable-android`; прежний React/Capacitor код остаётся в `src/` |
| Android-основа | Нативный Godot, меню, новая игра, выбор страны/города, горизонтальный сенсорный UI, сохраняемые настройки, 3D-город; фактический APK — см. VERIFICATION |
| Экономика | Единый двойной журнал, целые деньги, товарные/сервисные предприятия, FIFO/поставки/запасы, расходы/штат/налоги/кредиты, разные прибыль и денежный поток, банкротство |
| Конкуренты | Самостоятельные закупки, цены, штат, долг, реакция на спрос, расширение и закрытие; общий конечный рынок |
| Город | Четыре района, 16 участков, выбор, реальные здания, дороги, границы, мышь/касания, камера, выделение и предприятия |
| Финансовые системы | Кредиты/просрочки/штрафы/реструктуризация, покупка/продажа/содержание/ремонт/аренда собственности, дебиторская/кредиторская задолженность |
| Реальная экономика | Проверяемые справочные курсы ЦБ с офлайн-кэшем и датой, механизм проверки метаданных и будущих правил. Поток проверенных законов/налогов/новостей — следующий этап |
| AIRA | Локальный анализ фактического состояния и рекомендаций без платного API |
| Расширение | Конфигурации RU/US и двух городских профилей; США экспериментальный. Два профиля используют одну процедурную ограниченную сцену, не являются двумя отдельно созданными картами |
| Полировка | Пять тем, тёмный режим/акцент/карточки, прокрутка, переходы, обучение, история/достижения, регрессионные тесты и настоящий desktop-рендер. Android QA/FPS остаются непроверенными |

Дальше приоритетны реальная установка/проверка на Android и удобство на нескольких физических экранах. Затем — баланс экономики по игровым сессиям, более разнообразный трудовой рынок и поставщики, подробные юридические профили с рассмотренными изменениями, уникальные карты новых городов и расширение отраслей.

Строительство новых зданий и инфраструктуры, изменение населения/районов, международные филиалы, отрасли вне трёх текущих, полноценная мировая экономика и магазинная release-публикация не заявляются реализованными. Нет обязательных ежедневных заданий, регистрации или сетевых API для основного игрового цикла.
