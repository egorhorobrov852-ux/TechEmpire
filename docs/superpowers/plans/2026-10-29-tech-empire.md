# TECH EMPIRE Implementation Plan

Goal: нативный играбельный Godot-проект и debug APK, насколько позволяет окружение.
Architecture: независимые экономика, процедурный город, UI/сохранения, Android tooling. JSON-конфигурации, локальная детерминированная симуляция.
Tech Stack: Godot 4.6.3, GDScript, OpenJDK, Android SDK, GitHub Actions.
Spec: docs/superpowers/specs/2026-10-29-tech-empire-design.md

## Global Constraints

- Сохранить имеющийся исходный код. Ветка feat/playable-android.
- Не заявлять о проверках, которые не запускались.
- Денежные суммы — целые минимальные единицы; конечный спрос и реальные обязательства.
- Нативный Godot, без обязательных API/секретов/регистрации.

## Review Focus

Недостаток денег, пустой склад, повторное нажатие, повреждённое сохранение, уход приложения в фон. Проверять отказы до изменения состояния, восстановление и отсутствие потери прогресса.

## Tasks

- [x] 1. Аудит: репозиторий найден, клонирован, отдельная ветка создана; Godot 4.6.3 и JDK 21 есть, Android SDK отсутствует.
- [x] 2. Экономика: scripts/economy/simulation.gd, конфигурации data/, tests/test_economy.gd. Конечный спрос, журнал, три отрасли, персонал, поставки, ИИ, кредиты, налоги, недвижимость. Headless сценарии и инварианты.
- [x] 3. Город: scenes/city/city.tscn, scripts/world/city.gd. Ограниченная 3D карта, районы, выбор, камера, touch, подсветка и бизнесы.
- [x] 4. UI и сохранения: project.godot, scenes/main_menu/main.tscn, scripts/ui/, scripts/save_system/, scripts/data_sync/. Полный игровой цикл, темы, AIRA, обучение, резервное сохранение. Headless smoke сценарий.
- [x] 5. Android: export_presets.cfg, tools/, .github/workflows/build-apk.yml. Установка SDK/templates, импорт, тесты, debug export, подпись, артефакт; release документируется отдельно.
- [ ] 6. Интеграция: полные тесты, исправления, рендер, APK, проверка честного статуса. README, docs/VERIFICATION.md, git checkpoint, архив исходников и APK.

Разделение разрешено заданием пользователя «автономная команда». Реализацию ведут независимые специалисты без совместного редактирования файлов; интеграция и финальная проверка централизованы. Внешняя публикация/слияние в main не требуется.
