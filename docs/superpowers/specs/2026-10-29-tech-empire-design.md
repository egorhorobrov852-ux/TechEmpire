# TECH EMPIRE: первая нативная версия

Основание: подробное задание пользователя от 29.10.2026. Разработка разрешена автономно, без промежуточных согласований. Существующий React/Capacitor проект сохраняется как прежний прототип, нативная игра запускается через project.godot.

## Решение

Godot 4.6.3 / GDScript / Compatibility renderer; офлайн, ландшафтный мобильный интерфейс, процедурный ограниченный 3D-город. Россия — игровой калиброванный профиль, США — явно обозначенный экспериментальный профиль. Реальные текущие ставки не выдумываются: базовые параметры отмечены как игровые; проверяемые официальные источники и даты хранятся отдельно. Никакого IP-определения страны.

Первый релиз: ручной календарь, три отрасли (магазин, кафе, IT-услуги), дефицит и доставка, сотрудники, конкуренты с ограниченным спросом, кредиты, налоги, покупка/продажа собственности, прибыль/убытки/банкротство. Деньги — целые минимальные денежные единицы. Единый воспроизводимый журнал операций. Кредит и капитальные покупки не входят в выручку/расходы периода. Баланс и денежный поток проверяются автоматическими тестами.

UI: молочные карточки, мягкий жёлтый, 5 тем, темный режим, сохранение настроек. Реальные действия открываются в панелях поверх 3D-города; недоступные долгосрочные механики отмечаются «В разработке». AIRA — локальные рекомендации по игровым данным. Сохранения с checksum, резервом, версией и безопасной записью.

## Границы

Мировая экспансия, тысячи городов, полноценное строительство, юридическая модель всех стран, живой поток экономических новостей и магазинная публикация не считаются выполненными этим релизом. APK считается собранным только после реального успешного экспорта; запуск на устройстве — только при наличии устройства/эмулятора и фактическом тесте.

## Проверка

Headless импорт Godot, автоматические тесты экономики и сохранений, сценарий UI, настоящий рендер при доступном дисплее, экспорт debug APK, проверка подписи и package metadata. Полный перечень фактических проверок и ограничений — в docs/VERIFICATION.md.
