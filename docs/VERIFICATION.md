# Фактические проверки TECH EMPIRE

Дата финальной проверки: 30.10.2026 UTC. Основной стек: Godot 4.6.3 stable / GDScript, Compatibility renderer; Linux, OpenJDK21, Android SDK36 / build-tools36.0.0.

## Статус

Нативный проект и игровые системы реализованы. Финальный локальный pipeline `bash tools/build_android.sh` **завершился с кодом 0** 30.10.2026. Получен `artifacts/TECH-EMPIRE-debug.apk`, 55 918 132 байта, debug-подпись v2/v3 проверена. SHA256: `5a4502f88a1b5b7fd21c68783c39ebba7a368e89f883e99e6a5d3c64257bd68a`.

Исходный APK с SHA256 выше **фактически установлен и запущен на Android 11/API30, x86_64 эмуляторе**. Получен реальный кадр главного меню с русским интерфейсом и отрендеренным 3D-городом: [снимок Android](qa/android-menu.png). Godot 4.6.3 завершил setup и запустил main loop; в итоговых логах нет shader linking/uniform errors, crash buffer пуст. Использован host Mesa llvmpipe, software TCG без KVM.

Физический телефон, полный игровой сценарий и аппаратные касания, жизненный цикл Android при выгрузке процесса и производительность Android **не проверены**. Наличие меню не подменяет эти проверки. Подробный протокол: [ANDROID_RUNTIME_QA.md](ANDROID_RUNTIME_QA.md).

## Автоматические проверки

Фактически прошедшие финальные наборы, каждый запущен настоящим Godot:

Всего: **231 отдельная проверка и 1080 игровых дней стресс-сценария, 0 ошибок**. Проверены итоговые exit codes и `artifacts/logs/`; поиск `SCRIPT ERROR`/`ERROR` в финальных логах не нашёл ошибок. Стресс-проверка доказывает инварианты на названных сценариях; это не доказательство баланса всех возможных стратегий.

В ходе разработки регрессионные тесты сначала воспроизвели ошибки, затем прошли после исправлений: программный camera focus не вызывает рекурсивный пользовательский выбор; долг арендатора выплачивается собственнику; междневные расходы входят в налоговую базу; сумма нового товарного кредита учитывается до выдачи; собственный бизнес доступен после просмотра AI; семантически повреждённое сохранение не затмевает здоровый резерв; выходные спроса совпадают с отображаемым календарём.

В Android QA первоначальный legacy SwiftShader 4.0.0.1 ошибочно учитывал UBO в лимите обычных uniform-регистров и не компилировал стандартный Godot SceneShader. Причина независимо воспроизведена минимальным шейдером без игры на точной библиотеке эмулятора; тот же тест проходит на Mesa. Две экспериментальные настройки света не помогли и полностью откатились. При смене драйвера эмулятора на Mesa **тот же исходный APK** показал меню и город. Продуктовый код для обхода дефекта тестового драйвера не изменялся.

## Настоящий рендер и UI

Проект запущен через rootless Xorg, OpenGL Mesa llvmpipe, без headless-рендера. Сохранены реальные кадры меню, города, компании, финансов, AIRA и тёмной темы в `artifacts/screenshots/`. Визуально проверены молочно-жёлтая тема, читаемость, карта и панели. Воспроизводимый сценарий: `tools/capture_screens.gd`.

Ограничение окружения: dummy Xorg сообщает, что V-Sync не поддерживается. Это ограничение тестового дисплея, не замер Android FPS. Звуковое устройство не требуется: при проверке выбран `--audio-driver Dummy`.

Независимое ревью дополнительно фактически проверило ввод `300.50` в SpinBox и нажатие кнопки мышью: цена стала `30050` минимальных единиц. Сохранение при `NOTIFICATION_APPLICATION_PAUSED` проверено в работающем Godot. Это синтетические/desktop-проверки, не Android-устройство.

## Реальные данные

Bundled CBR XML действительно получен с официального `cbr.ru`, сохранён исходный ответ и SHA256. Запрос на 01.01.2025 вернул официальный курс с 29.12.2024; отдельная дата публикации не раскрыта и записана `null`. Архивный курс не называется текущим.
